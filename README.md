# Portfolio

My personal portfolio and research website, live at [sattari.org](https://sattari.org)

Built with Next.js, Tailwind CSS, shadcn/ui and Magic UI. It has a resume-style home page, publications with citation pages, academic project write-ups (MDX), writings, and a multilingual "How to work with me" user manual

## Credits

This site started from the open-source [portfolio template](https://github.com/dillionverma/portfolio) by **Dillion Verma** (MIT). Thank you, Dillion, for making it available. I have since extended and changed it a lot:

- Publications section with detail pages and citation export
- Academic projects with MDX articles
- Hackathons, workshops, volunteering, writings and digital resources sections
- Multilingual user manual
- Cookie-free Vercel Analytics, JSON-LD, sitemap, `llms.txt`

## ⚠️ Cloning this repo? Make it yours first

**Everything personal in this repo is mine** (name, photos, resume, projects, publications, logos, texts). If you use this as a template, please **remove or replace all of it with your own content** before you publish. Don't deploy my profile under your name

The full checklist of what to replace is in [AGENTS.md](AGENTS.md). If you use an AI coding agent, point it at that file and it will walk through the replacement with you

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000
